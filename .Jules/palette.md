## 2024-05-18 - Mobile Menu Accessibility and Tailwind Focus States
**Learning:** When adding keyboard focus states to toggle buttons using Tailwind (which often resets default browser outlines), ensure classes like `focus-visible:ring` and `focus:outline-none` are used for clear navigation. Furthermore, for toggle controls using Iconify components (where `<span class="iconify">` gets replaced by `<svg>`), ensuring `aria-expanded` is dynamically updated on the parent button is critical for screen reader users to understand the current state of collapsible menus.
**Action:** Always verify that interactive elements like mobile menu buttons have dynamic `aria-expanded` attributes bound to their JS state, and include explicit focus states (`focus-visible:ring`) to combat default style resets.
