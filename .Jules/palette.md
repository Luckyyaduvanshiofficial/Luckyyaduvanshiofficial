## 2024-07-29 - Managing ARIA Expanded State and Focus Outlines for Tailwind Toggles
**Learning:** Tailwind CSS resets default browser focus outlines, causing custom interactive toggle elements (like dark mode toggles or custom mobile menus) to become inaccessible for keyboard users if specific focus styles aren't added. Furthermore, custom JS-controlled toggles must have their `aria-expanded` state explicitly bound to the visual state of the element they control to be clear for screen readers, rather than just relying on generic button roles.
**Action:** Always add explicit focus-visible classes (e.g., `focus-visible:ring-2 focus-visible:outline-none`) to custom interactive elements in Tailwind projects, and ensure `aria-expanded` attributes are updated dynamically via JS corresponding to the visibility state of the controlled target.
