## 2024-05-18 - Explicit Form Requirements
**Learning:** Implicitly required form fields (where users only find out what's required after an error) create unnecessary cognitive load and frustration. Relying solely on HTML5 `required` validation isn't enough for good UX.
**Action:** Always provide explicit, visible indicators for required fields (like a red asterisk) and explicitly mark optional fields before the user starts filling out the form.
