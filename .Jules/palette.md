## 2026-08-22 - Navigation Accessibility Enhancements\n**Learning:** The application uses Iconify which replaces `<span>` tags with `<svg>` elements, meaning accessibility attributes (like `aria-label`, `aria-expanded`) and focus classes must be applied to the parent `<button>` wrapper, not the icon element itself. Additionally, Tailwind resets default browser focus outlines, so explicit `focus-visible:ring-*` classes are critical for interactive elements.\n**Action:** Always apply focus indicators and ARIA state attributes to the interactive wrapper elements (buttons/links) surrounding dynamic icons. Use `focus-visible:` for focus outlines to enhance keyboard accessibility without affecting mouse users.
