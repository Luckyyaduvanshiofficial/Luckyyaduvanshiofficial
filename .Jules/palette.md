## 2024-11-20 - [Focus Outlines with Tailwind CSS]
**Learning:** Tailwind CSS resets default browser focus outlines, making it difficult for keyboard users to navigate interactive elements.
**Action:** Explicitly add `focus:` or `focus-visible:` classes (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-brand-teal`) to interactive elements to ensure keyboard accessibility.
