## 2026-06-20 - Adding Skip to Content Link
**Learning:** Implementing a visually hidden but focusable 'skip to main content' link is an immediate and effective win for keyboard and screen reader accessibility, particularly for pages with large navigation headers.
**Action:** Prioritize checking for and adding this pattern on static sites, utilizing existing utility classes (like Tailwind's sr-only and focus modifiers) to implement it without adding new custom CSS.
