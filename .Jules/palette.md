## 2024-05-18 - Accessibility: Binding ARIA Attributes to JavaScript State
**Learning:** When creating custom toggle buttons for mobile menus or accordions, static ARIA attributes are insufficient for screen readers. The `aria-expanded` attribute must dynamically update to reflect the actual visibility state of the controlled element. Additionally, because Tailwind CSS resets default browser focus outlines, interactive elements must explicitly use focus utility classes (e.g., `focus-visible:outline-none focus-visible:ring-2`) to remain keyboard accessible.
**Action:** Always bind `aria-expanded` attributes to the JavaScript visibility state of the collapsible element. Explicitly add Tailwind focus rings (`focus:` or `focus-visible:`) to all custom interactive elements for keyboard accessibility.
